Help Center
Guides and FAQs for setup, knowledge base workflows, and post generation.

Get AI API Keys

Use your own key for the model provider selected in Settings → AI Provider.

  • Gemini: Open Google AI Studio, create/select a project, then generate an API key from the API Keys section.
  • Anthropic: Open Anthropic Console, create a key under API Keys, copy it once, and store it securely.
  • OpenAI: Open OpenAI dashboard, create a new secret key in API Keys, then paste into this app.
Paste key in Settings Click Update AI Settings One provider at a time

LinkedIn Access Token & Person ID

These are required for posting directly to LinkedIn from the platform.

  • Create a LinkedIn Developer app and configure OAuth redirect URI.
  • Complete OAuth authorization to obtain an access token.
  • Fetch profile data using LinkedIn API and copy your person URN (for example: urn:li:person:XXXX).
  • Save both values in Settings → LinkedIn Integration.
Knowledge Base & Templates Workflow

How to use Knowledge Base

  • Go to Knowledge Base tab and upload PDF, DOCX, TXT, MD, CSV, or PPTX files.
  • After upload, files are indexed for retrieval during generation.
  • In LinkedIn Post tab, select KB mode (all files, selected files, or no KB).

How to train/retrain Knowledge Base

  • Click Rebuild KB from All Files to reprocess everything.
  • Use rebuild after large file updates or replacements.
  • Watch status indicators for indexing progress and chunk counts.

How to create templates

  • Open Custom Template section and click New Template.
  • Name the template and select the relevant files.
  • Click Save Template to persist file mapping.

How to use templates in post generation

  • In LinkedIn Post tab, expand Selected Files & Workspace Templates.
  • Choose a template and click Apply Template.
  • Generate post to use that template's selected files as context.

FAQs
Why is post generation not using my uploaded files?

Check the LinkedIn Post tab and ensure Knowledge Base mode is set to either Use All Uploaded Files or Use Selected Files from Upload.

If you recently uploaded documents, run Rebuild KB from All Files and wait for indexing to finish.

Which template should I pick for a post?

Pick the template that best matches the exact subject of your post (for example, product updates, compliance, or market analysis).

Smaller, focused templates usually produce cleaner and more relevant output than very broad templates.

How do I verify API key and LinkedIn setup?

In Settings, save your AI key and LinkedIn credentials, then generate a sample post and use Post Now or Schedule.

If anything fails, re-check key validity, token expiry, and person URN format.
