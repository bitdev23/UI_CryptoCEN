# Master Prompt: Build a High-Converting 2-Page SaaS Website

Use this prompt in any LLM to generate your full website.

---

You are a world-class SaaS growth designer + front-end engineer + conversion copywriter.

Create a **modern, premium, conversion-focused 2-page website** for this product:

## Product Context
- Product name: **Fyrano AI** (you may suggest a stronger premium brand variant if needed, but keep Fyrano visible).
- What it does:
  - AI-powered LinkedIn content generation for founders/teams in crypto, fintech, and B2B.
  - Converts your knowledge base (PDFs/docs) into original, on-brand content ideas and drafts.
  - Includes planning, scheduling, and publishing workflow.
  - Includes subscription plans (INR pricing currently): 1 month, 3 months, 12 months.
- Core value: turn expertise into consistent authority content that drives inbound leads and revenue.

## Main Objective
Create a site that makes visitors feel:
1) “This solves my pain immediately.”
2) “This gives measurable business upside.”
3) “This is differentiated from generic AI writing tools.”
4) “This is affordable and a smart long-term investment.”

## Deliverable Format
Return production-ready code for a complete 2-page website:
- Page 1: **Home / Landing Page**
- Page 2: **Pricing + ROI / Why Buy Now**

Use one of these implementations (choose the best):
- Option A (preferred): Next.js + Tailwind + Framer Motion
- Option B: React + Tailwind + Framer Motion
- Option C: Pure HTML/CSS/JS with GSAP animations

Also include:
- reusable components
- clean folder structure
- all assets as placeholders
- fully responsive layout
- accessible semantics
- polished micro-interactions

## Target Audience
- Crypto founders, startup teams, growth marketers, founders building in public, consultants, and agencies.
- People with low time, inconsistent posting, poor reach, and weak lead flow.

## Conversion Goals
Primary CTA: **Start Free / Start 7-Day Trial / Upgrade Now** (choose strongest).
Secondary CTA: **Book Demo / Watch Platform Tour / View Dashboard Preview**.

## Messaging Requirements (Must Include)
### 1) Pain Points
Explicitly call out:
- Inconsistent posting because of time shortage.
- Generic AI output that lacks personal voice.
- No repeatable pipeline from knowledge to content to leads.
- Lost deal flow because audience does not trust inactive profiles.

### 2) Utility and Outcomes
Explain practical utility:
- Turn PDFs, docs, insights into ready-to-publish content.
- Maintain brand voice and domain authority.
- Plan content calendar and schedule posts.
- Get consistency with less manual effort.

### 3) Revenue Advantage (No fake guarantees)
Use realistic, ethical language such as:
- “potential pipeline growth”, “higher qualified inbound”, “more trust-driven conversations”, “shorter trust-building cycle”.
- Include an ROI explainer section with assumptions and example math (editable values).

### 4) Differentiation vs Other Apps + Generic LLMs
Create a strong “Why not just ChatGPT/other tools?” comparison:
- Knowledge-base grounded outputs
- Workflow + scheduling + consistency system
- SaaS workflow for teams, not one-off prompts
- Better for ongoing content operations, not just text generation

### 5) Investment Framing + Affordability Anchoring
Include persuasive but credible comparison copy like:
- “Less than a coffee-a-day equivalent”
- “Costs less than many daily impulse purchases while building long-term personal brand equity”
- “This is an investment in future deal flow and authority”

Do NOT use manipulative or deceptive claims.

## Visual + UX Direction
- Style: premium, modern, dark-light gradient accents, enterprise SaaS aesthetic.
- Must include tasteful animations:
  - hero reveal
  - animated metrics counters
  - scroll-triggered feature cards
  - CTA hover glow
  - testimonial carousel fade/slide
- Must include high-quality placeholder zones:
  - dashboard screenshot placeholders
  - platform walkthrough video placeholder
  - integrations strip placeholder
  - social proof logos placeholder
- Add subtle parallax/gradient blobs where appropriate.
- Keep it fast and clean; avoid visual clutter.

## Required Sections Across 2 Pages
### Page 1 (Home)
1. Hero with strong headline + subheadline + CTA + product visual placeholder
2. Pain points section
3. How it works (3-5 steps)
4. Feature blocks (AI generation, KB grounding, scheduling, analytics/insights)
5. “Why different from generic LLM tools” comparison module
6. Social proof/testimonials placeholders
7. FAQ accordion (8-12 questions)
8. Final CTA band + footer

### Page 2 (Pricing + ROI)
1. Plan cards (1 month, 3 month, 12 month)
2. Recommended plan highlight (usually 12-month best value)
3. Value stack section (what you get)
4. ROI calculator style section (inputs + output placeholders)
5. Cost comparison to daily spend habits (ethical, not insulting)
6. Objection handling section ("too expensive", "no time", "can use free AI")
7. Guarantee/risk-reversal style copy (non-legal placeholder)
8. CTA + FAQ + footer

## Copywriting Tone
- Confident, clear, premium, founder-friendly.
- Focus on outcomes and practical use.
- No hype spam. No fake urgency.

## SEO + Metadata
- Add title, meta description, Open Graph placeholders, Twitter card placeholders.
- Add structured headings and clean semantic HTML.
- Add CTA-focused microcopy.

## Technical Requirements
- Responsive for mobile/tablet/desktop.
- Smooth scroll and section transitions.
- Keep performance in mind (lazy-load placeholders, optimized animation usage).
- Use modern component architecture and clean code comments only where necessary.
- Include dummy assets and clear TODO markers for replacing screenshots/videos/logos.

## Output Requirements
1. Provide complete code for all files.
2. Provide a short “How to run” section.
3. Provide a “Where to customize” section (pricing, copy, brand colors, assets, FAQs).
4. Ensure there are exactly 2 pages and clear navigation between them.

## Conversion Copy Starters (Use/Adapt)
- Headline idea: “Turn Expertise Into Inbound Revenue — Without Spending Hours Writing LinkedIn Posts.”
- Subheadline idea: Fyrano AI transforms your docs and insights into consistent, authority-building content that compounds trust and opportunities.”
- CTA idea: “Start Building Authority Today”

Now generate the complete website.
